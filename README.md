# SiteStack
Phases 1–2: dashboard, cards, JSON data, categories, grid/compact/list, themes, search.
Dev: `pip install zensical && zensical serve` · Build: `zensical build --clean` · Deploy: push to `main` (Settings → Pages → Source: GitHub Actions).
For project sites set `site_url` in `zensical.toml`. Data lives in `docs/assets/data/` (seed); user data goes to localStorage only.
